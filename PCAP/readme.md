# Microchip PCAP Utility Tool
 This tool used to capture/sniff IEEE 802.15.4 Frames ( 2.4 GHZ & Sub Ghz)
 
## Description
 Microchip PCAP Utility Tool connects the Wireshark Graphical User Interface (GUI) and the sniffer firmware running on the ZigBit® USB stick. The sniffer captures the packets based on the channel and channel page selection. Captured data is sent to Wireshark software to show the decoded packets on the GUI. The sniffer captures IEEE® 802.15.4, Zigbee® packets or custom protocol.

## Downloading and Instalation Procedure
 For downloading Wireshark, go to https://www.wireshark.org/download.html.
 Note: The latest stable version of Wireshark is essential for the tool to function correctly. The user can install the latest development release available from the official Wireshark website.
